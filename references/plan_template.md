# 方案选择题模板

用纯文字在对话里给出 2~4 个方案，然后停下等用户回复。
各方案之间要有真实的差异，可以在风格、叙事结构、2D/3D 比重、节奏等维度拉开，不要只是换个配色。
推荐项放在第一个，并写一句推荐理由。

样张做法：每个方案调用 `gen_image.py --quality low` 生成 1 张，在对话里列出路径；或者用 `mcp__clawsgo__deliver_files` 一并交付，方便用户直接查看。

```
根据你的需求（<时长> / <画幅> / <用途> / <语言>），我准备了 3 个方案：

**A. <方案名>（推荐）**：<一句话概括，以及推荐理由>
- 参考图：refs/plan_A.png
- 风格：<画风、配色（主色 hex）、字体气质、节奏（平均每镜几秒）、转场>
- 关键镜头：
  1. <镜头内容>（2D / 3D / Manim）
  2. …
- 需要生成的图片：<数量>张，<分别是什么>
- 需要的 3D 模型：<用户提供的 xx.glb / 无 / 需要在 Blender 里搭建 xx>
- 音频：旁白 <音色名，例如 云希·男声·沉稳>，语速 <+0%>（不要旁白时写"无旁白，纯音乐"）；音乐 <用户提供的 / 无>，<BPM 与我对音乐情绪的理解，请确认>

**B. <方案名>**：…

**C. <方案名>**：…

请回复 A / B / C，也可以组合（例如"A 的风格 + B 的结构"）或提出修改意见。
```

用户选定后输出分镜表，等用户确认：

```
| 镜头 | 时长 | 类型 | 画面 | 旁白 | 素材 |
|---|---|---|---|---|---|
| S01 | 3s | 2D | 标题从暗场浮现，背景为 xx | 你有没有想过…… | images/s01_bg.png（生成） |
| S02 | 5s | 3D | 产品模型 360° 环绕，镜头缓慢推近 | …… | models/product.glb（用户提供） |
| S03 | 6s | Manim | 勾股定理面积拼图 | …… | manim/Pyth.webm |
```

- 有旁白时，时长用 `tts.py` + `timeline.py` 实测后再填（edge-tts 有句间停顿，按字数估算会偏短）；无旁白时按音乐小节排（120 BPM 一小节 2 秒）
- 表格后面附一句总时长。和用户要求的时长差距超过 15% 时，先调整文案再给用户看
