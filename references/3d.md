# 3D：@remotion/three 与 Blender

## 选择路线

| 情况 | 路线 |
|---|---|
| GLB/glTF，PBR 材质，面数 < 50 万 | 直接把文件放进 `public/models/`，镜头用 Model3D |
| .blend，或需要修改材质、灯光、动画、镜头 | 先用 blender-mcp 编辑，保存后用 `blender_tool.py export` 导出 GLB，再用 Model3D |
| 需要体积光、景深、焦散、毛发、复杂程序化材质，或镜头要求电影级画质 | 用 `blender_tool.py render` 渲染 PNG 序列，镜头用 ImageSequence |
| 模型自带骨骼动画 | 用 Model3D 的 `clip` 参数，按帧号 setTime 播放，可以逐帧确定地渲染 |

拿到模型后先运行 `blender_tool.py inspect`，它会输出 `tips`，提醒面数过高、贴图过大、程序化材质（导出后会丢失）等问题。

## Model3D 参数

- `model`：相对 public/ 的路径。模型会自动居中，并缩放到单位尺寸
- `orbit`：整个镜头内相机绕 Y 轴转过的角度，默认 30°
- `from`：起始方位角，默认 -15°
- `distance`：相机距离，是模型包围球半径的倍数，默认 3.4，此时模型正好完整入画；想要特写可以设 2~2.5
- `height`：相机仰角，默认 15°
- `push`：镜头内推近的比例，例如 0.15 表示推近 15%
- `light`：整体亮度倍数。画面偏暗时调到 1.5~2
- `bg`：背景图
- `ground`：是否显示接触阴影地面，默认 true；悬浮展示时设为 false
- `clip`：要播放的动画，可以是动画名或序号。**不写时会播放第 0 段**；模型自带动画和节奏不合时写 `false` 关闭
- `target`：相机环绕、注视的中心，`[x,y,z]`，归一化坐标（模型半径 = 1），做眼睛、按钮等局部特写用
- `lift`：镜头内模型在画面里上移的量（归一化单位），给下方标题留位置

环境光使用 RoomEnvironment（PMREM），金属和高光材质依赖它。如果反射看起来发黑，先调高 `light`。

## 写定制 3D 组件时

以 `src/shots/Model3D.tsx` 为模板来写，要守住这几条：
- 所有运动都由 `useCurrentFrame()` 计算，禁止使用 `useFrame`。Remotion 是逐帧截图渲染的，useFrame 会导致闪烁和不确定的结果
- 相机通过 `useThree` 拿到后，每帧设置 position 和 lookAt
- 模型用 `three/useGltf.ts` 加载（内部已处理 delayRender），同一个模型在多个镜头里用时要先 `SkeletonUtils.clone`
- 动画用 `mixer.setTime(frame / fps)`，不要用 `mixer.update(delta)`
- 不使用 drei，模板中没有安装它，需要的功能直接用 three 的 examples/jsm 实现
- 渲染设置已配置为 `setChromiumOpenGlRenderer("angle")`，不要改动

## Blender 二次编辑（blender-mcp）

1. 先读 blender-mcp skill。用 `get_objects_summary` 了解场景结构，不要盲改
2. 编辑操作优先用 `bpy.ops`，并在操作前设置好 active object 和选择
3. 改完后保存 .blend 到 `<项目>/blender/`。不要直接覆盖用户的原文件，另存一份
4. 导出：`blender_tool.py export blender/x.blend public/models/x.glb`。导出时不应用修改器，带上动画，+Y 朝上
5. 程序化材质（噪波、渐变等节点）导出 GLB 会丢失，要先烘焙成贴图，或者改走渲染序列帧的路线

## blender-mcp 没连上时

用户没开 Blender 图形界面时，把编辑写成 bpy 脚本后台执行（导入模型 → 修改 → 另存 .blend）：

```bash
python $VS/scripts/blender_tool.py script refs/model.glb blender/model.blend --py blender/edit.py
```

脚本里可以直接用 `bpy`，模型已导入（.blend 已打开），执行完自动另存为输出 .blend。之后照常 `export` / `render`。
低面数、平直着色的模型（inspect 会提示）进 Remotion 后满是棱面，可在脚本里加细分 + 平滑着色：

```python
import bpy
for o in [o for o in bpy.context.scene.objects if o.type == "MESH"]:
    o.modifiers.new("sub", "SUBSURF").levels = 2
    for p in o.data.polygons: p.use_smooth = True
    bpy.context.view_layer.objects.active = o
    bpy.ops.object.modifier_apply(modifier="sub")
```

## Blender 渲染序列帧

```bash
python $VS/scripts/blender_tool.py render blender/x.blend public/renders/S03 --start 1 --end 120 --size 1920x1080 --fps 30 --engine eevee
```

- 帧数等于镜头秒数 × fps。先跑一遍 `timeline.py` 拿到镜头的确切帧数，渲染时可以多渲染 10 帧作余量
- 默认用 eevee，速度快。需要真实光线追踪时用 cycles（会自动调用 OPTIX/CUDA GPU），`--samples 64` 一般够用
- 渲染时间长的话，先用 `--size 960x540 --end 10` 试几帧，确认构图和亮度后再正式渲染
- 镜头中的相机、灯光和动画都在 .blend 里设置好，脚本只负责渲染
- 输出 `0001.png…`，分镜里写 `"props": {"frames": "renders/S03", "count": 120}`

## 常见问题

- **3D 画面过暗**：调高 `light`；在 Blender 中检查是否有灯光、World 强度是否足够。GLB 不携带 World 光照
- **金属过曝发白**：默认灯光组合下 `light` 超过 1.2 金属就容易发白，调回 0.8~1
- **穿模或被裁切**：调大 `distance`，或者调整 `height` 和 `from`。模型原点偏移已自动居中，一般不会出问题
- **贴图丢失**：.gltf 引用的外部贴图要和模型放在同一目录；或在 Blender 中用 `export` 重新导出成单文件 GLB
- **模型朝向不对**：在 Blender 中旋转后应用变换（Ctrl+A），然后重新导出
